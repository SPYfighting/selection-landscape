# Synthetic model example

Every sequence and label in this directory is artificial. This example demonstrates file formats, fitting, exclusion of observed pairs, prediction and grouped evaluation; it is not a performance benchmark.

From the repository root, after installing the package:

```sh
python examples/model/run_synthetic_example.py --output synthetic-model-output
```

The output directory must be new. The script writes a model JSON, four unseen candidate identities, their predictions, metric summaries and 2,000 bootstrap replicates, and checks the expected result.

The predefined single-mutant effects are `A1V: 0.6`, `C2S: 0.2`, `D3N: -0.1` and `E4Q: -0.4`. The WT label is 0.5, and each single-mutant label is `sigmoid(effect)`. Double-mutant labels are generated by `sigmoid(0.1 + 0.8 × (effect_1 + effect_2))`, without noise. These parameters and the expected order are saved in `synthetic_definition.json`; they are chosen independently of fitting.

Two doubles, `A1V__C2S` and `D3N__E4Q`, calibrate the model and are excluded from candidate enumeration. The four remaining combinations have the following independently defined target scores:

| Rank | Candidate | Generating score |
|---|---|---|
| 1 | A1V__D3N | 0.6224593312018546 |
| 2 | A1V__E4Q | 0.5646362918030292 |
| 3 | C2S__D3N | 0.5448788923735801 |
| 4 | C2S__E4Q | 0.4850044983805899 |

The script checks this order and agreement within 0.0001, allowing for numerical optimization tolerance. Evaluation uses these noiseless generating labels. High agreement in this constructed example tests implementation behavior, not experimental predictive performance.

See [model documentation](../../docs/model.md) for the mathematical definition, label requirements and application limits.
